# 事实核验与证据标准

加载时机：需要判断"这条信息能否进事实基线、可信到什么程度、数字或视觉材料是否可靠"时。SKILL.md §3.4–§3.5、§4.1 是执行入口，本文件提供核验标准与自检清单。

## 1. 核验状态四档（统一口径）

全技能只用这四档，不引入第二套术语（如"较可信/尚无定论"）：

| 档位 | 含义 | 报告写法 |
|------|------|----------|
| 已确认 | 有可靠证据支持、基本无实质争议 | `[已确认]` + 一手来源链接 + 事件时间 |
| 媒体报道·待一手核实 | 权威媒体独立报道、无一手原文 | `媒体报道：据XX媒体报道…` + 来源 + `[待一手核实]`；禁写 `[已确认:据XX媒体]` |
| 待核实 | 单一来源 / 传言 / 搜索摘要 / 社交转述 | `[待核实]` + 来源 + 缺口说明 |
| 存在冲突 | 不同来源相互矛盾且无法判定 | `[存在冲突，暂无法判定]` + 各方来源 |

硬边界：
- 不能把尚未证实写成已经证伪；
- 一手来源只确认其直接能证明的事实（发布行为、文件内容、明确记录的事件），原因/责任/性能/效果主张须独立核验；
- 窗口外背景不自动降为待核实——三年前的政策原文只要原文可读、元数据可追溯仍可靠，按自身证据独立判级，只不计入本窗口进展/热度（SKILL.md §3.4）；
- **权威性按具体问题判断，不等于媒体知名度，也不等于官方身份**：看四项——直接证据（是否掌握一手材料/现场/原始数据）、专业能力（专业知识或法定职责）、信息透明度（是否说明来源/方法/口径/可追溯）、可交叉验证性（能否被独立来源印证）。社会热点按事件性质综合取源，不要求以新闻媒体为主；国际热点的政府/外交部门/国际组织一手声明、当地及不同立场媒体、智库/学术机构分析、条约/公开文件/统计数据/历史资料，都按此判断后取用。不因大媒体或官方身份默认其陈述为事实，也不因非知名媒体就排除。
- **四类信息必须分开，不得互相顶替**：事实（可核验发生了什么）、官方立场（某方公开表态/主张）、专业分析（机构或专家的解释判断）、个人观点（个人评论推测）。任何一方的表态——包括官方声明、权威媒体结论、专家判断——只证明"该方作出该表态"这一事实，其主张内容仍须独立核验，不得因来源权威直接写成已证实的事实。
- 来源冲突、证据缺失或明显矛盾时披露问题，不机械服从来源等级。

## 2. 反证检验
按结论的重要性、争议程度与潜在影响主动寻找：反例、反面证据、竞争性解释、不利于当前判断的材料、其他可能的因果机制。避免只收集支持预设结论的信息。未检出反证时如实写"未检出反证"，不假装做过。

## 3. 数字与统计审查
逐项检查：数据来源 / 统计口径 / 样本范围 / 分母与基准值 / 时间范围 / 比较条件 / 平均数与中位数 / 绝对数与相对数 / 排名规则与权重 / 是否选择性呈现。数字正确不等于由数字得出的结论正确。互动量≠观点支持人数≠整体民意。

## 4. 图片与视频核验
按话题性质采集视觉材料。重要材料尽量核实：原始发布者 / 拍摄时间与地点 / 原始文件及上下文 / 是否剪辑拼接或移花接木 / 是否旧图新用。区分现场记录、媒体制作素材与示意图片。AI 检测工具只作辅助判断，不能作为真实性的最终裁决。

## 5. AI 生成内容与深度伪造
综合使用：来源追溯 + 原始文件检查 + 传播链分析 + 技术检测 + 独立证据交叉验证。单一检测结果不足以定真伪。

## 6. 资料冲突处理
出现矛盾时优先参考权威来源与一手材料，同时检查其证据基础；保留无法解决的分歧，不为文章完整性强行给出确定结论。

## 7. 证据等级与三维不混算（铁律重申）
- A/B/C/D 标在单条证据 Enn 上（A=完整一手原文+可追溯元数据；B=二手/部分可读/有效聚合指标；C=仅确认存在性；D=无法获取且无投喂），不标整条事实，不能写"F01=A"。
- 评论文本可读可维持 A 级，但只证明该评论本身的存在与内容，不得外推为视频正文或产品事实；播放/评论/弹幕总数是 B 级聚合指标。
- 不给综合置信度总分或热点指数；核验状态 / 证据等级 / 来源覆盖度三维互不换算。
- 跨源旁证须独立：两个平台转载同一通稿不算两条独立旁证，不得据此升级核验状态。
- 任何字段缺失用 `[需核实:字段名]` 占位，不填猜测值。

## 8. 核验自检清单
- [ ] 权威性按具体问题判断（直接证据/专业能力/透明度/可交叉验证），未因媒体知名度或官方身份默认陈述为事实
- [ ] 事实、官方立场、专业分析、个人观点四类已分开，任何一方的表态都未被直接写成已证实的事实
- [ ] 未经证实的内容没有被写成事实
- [ ] 来源观点、作者判断与事实三者可区分
- [ ] 关键事实有可靠来源且优先一手/权威
- [ ] 转载没有被误当独立证据
- [ ] 反例与竞争性解释已检索
- [ ] 统计口径、样本、分母、时间范围清楚
- [ ] 相关性与因果没有被混淆
- [ ] 数字正确且结论由数字支持
- [ ] 不确定性已披露，预测与事实已区分
