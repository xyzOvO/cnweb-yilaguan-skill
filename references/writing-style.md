# 文章写作规范（文章模式专用）

加载时机：用户要求"写成文章 / 写篇文章 / 深入分析 / 流畅叙述"，或深度理解档输出文章模式时。简报模式（00–06 核验视图）不加载本文件。

## 目录
1. 整体风格 2. 篇幅 3. 开头 4. 主体结构 5. 专业术语 6. 原话引用 7. 数据与研究 8. 多方观点 9. 案例 10. 段落与小标题 11. 第一人称边界 12. 结尾 13. 视觉辅助与来源展示 14. 文章模式自检

## 1. 整体风格
目标风格：像一个真正理解话题的人，在知乎或高质量论坛上认真写出的一篇专业、自然、通俗易懂的文章。专业但不晦涩；通俗但不牺牲准确性；有信息密度但不堆砌；有独立判断但不武断；有叙事感但不制造标题党；避免机械化 AI 提纲与新闻列表。

## 2. 篇幅
默认 800～1500 字，无硬性上限。简单话题尽量简洁；复杂话题允许延长；不为字数填充，不为压缩牺牲关键背景与逻辑。研究可以深入，但正文应高效传递理解——不把所有采集到的资料都塞进正文。

## 3. 开头
自适应选择：直接给出核心结论 / 从具体事件切入 / 从关键问题切入 / 简要说明选题角度。不固定套路，不制造无意义悬念。

## 4. 主体结构
主线围绕核心问题展开，不套统一章节。按需组织：事实基线 / 历史背景 / 事件发展 / 多方观点 / 关键证据 / 底层机制 / 影响分析 / 争议与不确定性。
文章模式不强制出现 00–06 编号，但事实仍须可追溯：重要事实用轻量标注指向 Fnn/Enn，或在文末来源列表中对应。

## 5. 专业术语
中文优先。首次出现时给成熟中文译名 + 英文原名 + 通俗解释，后续用简称。无准确中文译名时保留英文并解释含义。黑话、缩写、网络用语结合语境解释，不为通俗牺牲准确性。

## 6. 原话引用
普通信息可转述；重要声明、争议表述与代表性原话可直接引用，保留来源与上下文，避免断章取义。复杂专业内容必要时逐句解释。

## 7. 数据与研究
普通数据说明其意义；重要数据交代来源、口径与测量条件。科研结果必要时说明研究方法、样本、实验设计、对照条件、局限、是否有独立复现。不把单项研究包装成普遍定论。

## 8. 多方观点
尽可能还原不同参与者有说服力的论据，必要时呈现反驳、适用边界与证据差异。不刻意追求表面平衡，不制造稻草人。

## 9. 案例
案例服务于解释。一个案例足够时不堆砌，多个确有帮助时再比较。真实案例提供来源，假设案例明确标注。

## 10. 段落与小标题
段落长短自然结合，避免文字墙，也避免每句话独立换行。小标题以内容概括型为主，让读者一眼看出本节内容。

## 11. 第一人称边界（有限允许）
事实介绍尽量客观，不用"我认为"包装事实。分析与趋势段可自然使用"我认为 / 我的理解是"，但必须：①挂靠 01 的 Fnn 已核验事实；②是推理而非新事实；③不虚构身份、经历或亲历。不因允许第一人称就把推测写成定论。文章不是资料汇编——证据充分时应给出独立判断。

## 12. 结尾
优先：归纳核心结论 → 必要时分析后续趋势 → 指出值得关注的关键变量和信号。不强行升华，不为结尾重复全文。

## 13. 视觉辅助与来源展示
视觉辅助服务理解而非装饰：技术架构用结构图 / 事件发展用时间线 / 数据变化用图表 / 多方关系用关系示意图 / 空间关系用地图。不强行插图；图表必须有来源，模型绘制的示意图明确标注。
来源：文末统一简单链接列表，按正文引用顺序排列，尽量提供机构或作者、资料名称、发布时间、原始链接。正文保持流畅，但不能以文末列出来源为由降低事实可追溯性。

## 14. 文章模式自检
- [ ] 普通读者能读懂，无术语堆砌与无意义重复
- [ ] 主线清晰，未为全面偏离核心问题
- [ ] 事实 / 观点 / 分析 / 预测可区分
- [ ] 第一人称只出现在分析段且挂靠 Fnn
- [ ] 重要数据有来源与口径
- [ ] 结论有证据支持，不确定性已披露
- [ ] 开头不悬念、结尾不升华
- [ ] 文末来源与正文引用对应
