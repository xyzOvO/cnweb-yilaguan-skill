# 研究方法：选题、采集与分析

加载时机：需要判断"值不值得研究、采哪些来源、如何解释机制"时。简单话题或用户已给明确方向时可只读 SKILL.md §3.1–§3.2，不必加载本文件。SKILL.md 的流程是执行入口，本文件提供其背后的研究方法判断。

## 1. 选题与研究入口

### 1.1 用户未指定方向时主动选题
综合以下维度，不按热搜排名单独决定：近期重要进展；对社会/产业/公众的影响面；争议程度；信息增量（相对已有公开讨论）；长期价值；可靠资料可获得性；是否存在值得解释的深层问题。
存在多个候选时：有明显主次则建主线+支线；同等重要则分别解释其关系；只有一个真正重要就把它讲透。不为"全面"罗列新闻。

### 1.2 话题类型识别
判断属于事件型 / 议题型 / 趋势型 / 技术型 / 争议型，可同时属于多类。类型决定研究方法侧重（见 §5），不改变 SKILL.md §3.4 的核验四档。

### 1.3 核心问题驱动
先找到话题最值得回答的核心问题，再建立叙述主线；子话题作为支线服务主线，不平铺百科目录。

## 2. 信息采集策略
按 SKILL.md §3.2 分源顺序执行。来源清单按话题选用，非全量必采：
1. 官方网站、公告、政策文件
2. 权威新闻媒体
3. 专业机构与研究报告
4. 学术论文与科研资料
5. 企业、组织、当事人公开材料
6. 社区：知乎、贴吧、微博、Reddit、论坛、评论区
7. 原始图片、视频、录音、现场记录

社区信息是重要研究材料（社会争议、产品口碑、公众体验、群体情绪），处理规则见 §3。领域专属来源按 SKILL.md §2.4 的核验标准补充（论文库/财报/政府公告/监管披露/通讯社等），抓不到如实标注，不虚构。

## 3. 社区观点、去重与传播链

### 3.1 社区观点五分
必须区分：个体经历 / 典型案例 / 群体倾向 / 可验证事实 / 整体社会态度。不把高赞评论等同社会共识，也不只采集支持主流判断的观点（反证见 §5.6）。

### 3.2 去重与传播链
- 优先寻找原始来源；
- 识别转载与引用关系；
- 保留有独立验证价值的来源；
- 必要时追踪传播路径与叙事变化；
- 禁止把大量转载包装成多方独立证实（与 SKILL.md §4.1"跨源旁证须独立"一致）。

## 4. 利益关系与信息操纵

### 4.1 利益关系调查（只呈现有可靠依据的）
企业商业利益 / 机构职责与立场 / 研究资助来源 / 政策利益主体 / 媒体或发布者背景。区分：已知利益关系 / 合理推断 / 未经证实的动机猜测。

### 4.2 信息操纵识别
关注：水军或疑似机器人账号、集中转发与异常传播、营销号带节奏、断章取义与选择性曝光、批量相似内容、利用虚假材料影响认知。
证据边界：不能仅凭账号活跃度、相似文案或转发数量认定存在组织操纵，更不能无证据推断幕后主体。发现异常只描述可观察的传播模式并标 `[待核实]`。

## 5. 专业分析方法（核心增量：解释"为什么"）

SKILL.md 擅长"发生了什么"，本组方法回答"为什么发生、意味着什么"。按核心问题选用，不为全面堆砌；证据不足时不强行建立因果。

### 5.1 历史脉络
起源 / 关键事件 / 重要转折 / 发展阶段 / 当前状态。只保留真正影响今天的节点，历史服务于理解当下。

### 5.2 底层机制
按话题调用：技术原理 / 经济机制 / 制度设计 / 组织运行 / 社会心理 / 市场竞争 / 政治与国际关系。解释现象背后的运行逻辑，而非仅描述现象。

### 5.3 跨学科
由核心问题确定主学科与辅助学科；不预设单一学科永远占主导，也不为全面堆砌知识。

### 5.4 关键变量（复杂话题）
识别：核心变量 / 辅助因素 / 约束条件 / 变量间相互作用 / 可能改变结论的关键条件。

### 5.5 人物与机构
按实际影响介绍；必要时解释身份、职责、历史表现、利益关系与实际作用。区分正式职务、实际影响力、公开立场与外界推测。

### 5.6 理论与学派 + 反证检验
理论分歧重要时解释核心观点 / 前提 / 论据 / 适用范围 / 局限；已有明确共识时不刻意制造争议。
主动找反例、反面证据、竞争性解释、不利于当前判断的材料、其他因果机制，避免只收集支持预设结论的信息。

### 5.7 横向比较
以当前话题的本地视角为主；只在比较有助理解时引入其他国家/地区/企业/组织案例。注意制度环境、文化背景、发展阶段与统计口径是否可比。

### 5.8 预测与趋势
允许基于事实、历史规律与关键变量做合理预测，须说明推理依据并区分：已发生的事实 / 当前趋势 / 合理预测 / 假设情景。不把预测写成确定事实。

## 6. 与核验铁律的衔接
本文件所有分析产出必须：
- 事实主张回到 SKILL.md §3.4 四档核验，分析段落用 Fnn 挂靠已核验事实；
- 证据等级 A/B/C/D 仍按 §3.5 标在单条证据上，分析不提升证据等级；
- 核验状态 / 证据等级 / 来源覆盖度三维互不换算（§4.1），不给综合置信度；
- 不编造来源、数字、原话；缺失标 `[需核实:字段名]`。
