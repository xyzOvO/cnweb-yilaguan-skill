# cnweb-yilaguan-skill

面向公共话题的研究、理解与文章生成引擎。给定话题，采集国内外公开信息，核验事实、解释机制、分离观点、识别争议与变化，输出结构化简报或 800–1500 字文章；抓不到时支持用户投喂。

纯提示词 Agent Skill（DeepSeek Harness），不含爬虫程序。仅供一般信息参考，不构成专业建议。

## 能力

- 事实基线：事实（Fnn）挂证据（Enn），时间线节点（Tnn）对应
- 四档核验：已确认 / 媒体报道·待一手核实 / 待核实 / 存在冲突
- 证据 A/B/C/D 标在单条证据上，不给整条事实或平台贴标签
- 三维不混算：核验状态、证据等级、来源覆盖度彼此独立，不做换算
- 观点四层：主体表态 / 推测 / 分析 / 舆论；评价类只呈倾向不判好坏
- 来源关系链：原创/转载/同源记后台，同源多条只算一条
- 技术日志后台化，对话只留正文

## 安装

**最省事**：把这个 GitHub 项目的地址发给你的 Agent，说一句"帮我安装这个 skill"，它就会照下面的结构放到位。

**手动放**：把本目录的 `SKILL.md` 和 `references/` 一起放进 DSH 技能目录，目录名与 frontmatter `name` 一致：

```
~/.dsh/skills/cnweb-yilaguan-skill/
├── SKILL.md
└── references/
    ├── research-methods.md
    ├── verification.md
    ├── writing-style.md
    └── tracking.md
```

## 用法

不用提技能名，直接说人话就会触发。默认窗口近 30 天，可说"近 7 天/近 90 天"改。

**常见说法**

```
总结一下"XXX"                    # 舆情/事件总结
跑一轮：XXX 好不好看              # 评价·风评：呈倾向，不判好坏
快速看看 XXX / 一句话说清 XXX     # 简洁模式快讯
深度核查 XXX / 逐条核实 XXX       # 严谨模式完整核验
把 XXX 写成一篇 1000 字文章       # 文章视图
追踪这个话题，附上次的简报：（粘贴上一份完整简报）  # 有基线才做变化对比
```

**模式与视图**：说"简洁/默认/严谨"直接切模式，说"写成文章"切文章视图；不说就按话题自动判定（见下两节）。

**抓不到时投喂**：遇到登录墙/反爬，可贴公开链接、正文、截图或文件作为证据。Cookie 默认不要求也不引导；提供后不回显不复用、限流即停。

**怎么看输出**：先看"先看结论"（从已核验事实提炼），再按需往下读。

- 想快速了解：读"先看结论" + 00 本期变化
- 想理解来龙去脉：读 01 事实基线 → 02 时间线 → 03 多方观点 → 04 已确认与争议 → 05 影响与关注
- 想核对来源：跳 06 来源

技术日志（检索式清单、时间戳换算、F/E/T 映射）写入后台 `runs/`，不占对话版面。

## 三种模式

| 模式 | 信号 | 映射 |
|------|------|------|
| 简洁 | "快速看看/一句话" | 快讯档 + 简报视图，四项核验限制极简保留 |
| 默认 | 无特殊要求 | 标准简报 00–06 |
| 严谨 | "逐条核实/深度/要决策" | 深度档 + 完整核验密度（F/E/T 展开、反证、自检表） |

自动判据：高争议/高影响/要决策→严谨，单一明确低争议→简洁，其余默认，拿不准问用户。优先级：显式模式 > 档位词 > 视图词 > 自动判据。三模式不改核验铁律。

## 两种视图

- **简报视图（默认）**：先看结论 + 00–06 正文 + 来源附录
- **文章视图**：用户说"写成文章/讲讲来龙去脉"时启用，800–1500 字，加载 `references/writing-style.md`

分析/趋势段可用有限第一人称，须挂靠事实、是推理非新事实；事实段客观。

## 质量保障

建议维护一套回归评测集（项目元资产，不随技能分发），含真实话题用例、覆盖矩阵与回归哨兵。三态判定：PASS（有运行证据）/ FAIL（明确违反）/ INCONCLUSIVE（测试不足，不当作通过）。每次改动后按评测集回归，任一铁律哨兵失败即回退。

## 推荐配套工具

工具可用性随环境而异；发现层引擎是否可用以 `free_search_test` 为准（key 未配置的引擎会失败）。建议在项目内维护一份工具实测台账（运行时元资产，不随技能分发）。

| 工具 | 用途 | 在本技能中的角色 |
|------|------|------------------|
| `web_search` / `advanced_search` | 通用发现，候选 URL/标题/摘要；后者支持 `timeRange` | 主力发现层 |
| `argo_search` | 多引擎/社交/本地统一搜索，可指定 engine、depth、时间范围 | 补充发现，社交与站内 |
| `argo_fetch` | 正文抓取，自动处理公众号/PDF、反检测浏览器兜底 | 原文获取；robots/登录墙失败即降级 |
| `bili_search` / `bili_comments` / `bili_subtitle` | B站视频、评论、字幕公开接口 | 国内平台采集主力 |
| `wiki_recall` / `wiki_context` / `wiki_verify` | 本地知识库（wiki-notes）检索并给出处证据 | 有本地资料沉淀时补证据、核原文 |
| `platform_search` | GitHub/知乎/豆瓣等站内搜索 | 定点查源 |
| `free_search_test` | 检测各搜索引擎是否可用 | 诊断，不入流程 |
| `ops_bash` | 命令执行（时间戳换算等） | 辅助 |

## 边界

- robots/登录墙/反爬失败即降级换源，不硬绕
- 知乎/小红书/抖音/快手依赖用户投喂；Cookie 默认不要求不引导，提供则不回显不复用、限流即停
- 热度与评分多为媒体转述，未抓原文标 `[需核实]`
- sandbox 时区失效时按 UTC+8 固定偏移换算并注明
